## Teaspot bugs and improvement suggestions

|ID	|TS-1|
|:---|:---|
|Тип	|Дефект|
|Модуль	|Карточка товара|
|Приоритет	|Низкий
|Серьезность	|Критическая
|Исполнитель	|Жукова Татьяна	
|||
|Заголовок	|Отсутствие пересчета цены при изменении фасовки для прокрученных товаров в блоке «Смотрите также»|
|Описание	|В блоке "Смотрите также" для товаров, которые становятся видимыми только после прокрутки слайдера (3 и более кликов по стрелке вправо), некорректно работает выбор фасовки. При изменении веса товара стоимость не пересчитывается, из-за чего любой вес можно добавить корзину по цене изначально отображавшейся фасовки (можно заказать больший объем по минимальной цене или наоборот)|
|Предусловия	|-|
|Шаги воспроизведения|	1. Перейти на страницу любого товара, например: https://teaspot.ru/shu_puer/tproduct/487597910042-gu-shu-tszin-hun-yulishan-2022g-357-gr
2. В блоке "Смотрите также" 4 раза нажать на стрелку вправо, чтобы в карусели отобразились скрытые ранее товары
3. Выбрать товар, который появился в блоке только после 3-го (или последующего) клика и имеет выпадающий список вариантов фасовки
4. В выпадающем списке этого товара выбрать любое значение, отличное от дефолтного
5. Нажать кнопку ""Заказать"" и проверить стоимость позиции в открывшейся корзине"|
Ожидаемый результат	Цена товара динамически меняется в соответствии с выбранной фасовкой. В корзину добавлен товар с корректной стоимостью, привязанной к выбранной фасовке
Фактический результат	Цена товара не изменяется. В корзину добавлена выбранная фасовка по стоимости дефолтной фасовки (добавлен больший вес товара по заниженной стоимости/добавлен меньший вес по завышенной стоимости)
Окружение	Windows 10 Pro Version 22H2 Google Chrome 155.0.8059.85
